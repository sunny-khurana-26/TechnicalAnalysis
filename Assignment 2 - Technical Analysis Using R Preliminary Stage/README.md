# TechnicalAnalysis — Assignment 2

This repository is the reproducible preliminary stage for BDA400 Assignment 2, Technical Analysis Using R. It contains portfolio.txt, R functions for loading and analysing stock data, display/visualization utilities, deterministic offline sample data, tests, and genuine local R runtime evidence.

## Repository layout

- portfolio.txt — one stock symbol per line (AAPL, MSFT).
- R/analysis.R — load_stock_data(), calculate_statistics(), and portfolio helpers.
- R/display_visualization.R — display, summary-table, and PNG visualization functions.
- data/*_sample.csv — deterministic offline data used for testing and demonstrations.
- tests/test_analysis.R — base-R assertions.
- report-assets/closing_prices.png — genuine PNG generated by the local R display script.
- ../work/runtime/ — captured local R 4.2.3 environment, test, and display console output.
- `Assignment 5 - Technical Analysis Using R Development Stage/` and `Assignment 6 - Technical Analysis Using R Visualization Stage/` are added in the shared course repository.

## Run with Yahoo Finance data

Install required packages in R/RStudio:

    install.packages(c("quantmod", "TTR", "zoo"))

Then run:

    source("R/analysis.R")
    prices <- load_stock_data(source = "yahoo")
    stats <- calculate_portfolio_statistics(prices)

Yahoo loading requires an internet connection and may be affected by provider availability. The included sample path is the deterministic evidence path and does not require packages or network access. The TTR package is installed as required by the assignment and is available for later technical indicators; the preliminary-stage moving average is intentionally implemented with base R for portability.

## Reproducibility notes

The statistics use the Adjusted price column. The moving average is a trailing five-observation simple moving average; its first four values are NA because a full window is not yet available. The mode returns the first value among tied modes after sorting by R's table naming order.
